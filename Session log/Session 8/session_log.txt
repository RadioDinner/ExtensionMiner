HOW LAYER 2/3 WORK END-TO-END (the new manual flow)
================================================================================
1. Open an extension → "🧠 Deep-dive layers". Layer 2 unlocks once Layer 1 is done.
2. Click "Generate research prompt" → "Copy research prompt".
3. Paste it into a Claude session with the DEEP-RESEARCH SKILL; run it.
4. Export the result as a PDF; back on the dashboard, upload the PDF (or paste the
   report text). The report MUST end with the JSON block the prompt specifies
   (between ===EXTENSIONMINER-JSON=== … ===END-EXTENSIONMINER-JSON===).
5. The page renders the report + structured competitors/opportunities. Layer 3
   (financial) unlocks once Layer 2 is done; same flow.
