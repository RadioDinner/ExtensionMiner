DIRECTIONAL DECISIONS
--------------------------------------------------------------------------------
  * Scraper + analysis: Python.
  * Database: Supabase (Postgres). All scraped data lives there.
  * Dashboard: Next.js on Vercel (chosen as the canonical Vercel framework,
    since the user said "whatever is best to use to host on vercel"). Revisit if
    a lighter static-export setup is preferred.
  * "Occur at the start of every session" is implemented two ways: (a) CLAUDE.md
    is auto-loaded every session, and (b) a SessionStart hook injects the
    protocol + latest handoff as additionalContext.
  * Strategic focus captured in CLAUDE.md/README: target ~3-star, high-install
    extensions with recurring complaints and "I'd pay if X worked" review
    signals — the competitive sweet spot.
  * Migration numbering: counts DOWN from 999 (999 = oldest). Documented in
    CLAUDE.md and supabase/README.md.
